Planche du jour et tolérance : les deux emplacements

Tu hésites entre l’en-tête de la phrase et la ligne « Maintenant » : on met les deux, avec une option dans les Réglages pour choisir (provisoire). Les petits points étaient l’interrupteur de tolérance : trois points pour Prudent, Normal, Motivé, le point allumé étant ton mode. Je trouve ça peu clair : voici aussi une version avec le mot écrit.
