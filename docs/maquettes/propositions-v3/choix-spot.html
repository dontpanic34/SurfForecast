Choix du spot : à remettre au propre

Ce qui est brouillon aujourd'hui. (1) Cinq rangées de filtres avant de voir un seul spot : pays, puis région, puis la liste. (2) Les étoiles sont sur chaque ligne sans dire qu'on n'a que trois favoris : on touche une étoile, il se passe quelque chose d'incompréhensible quand les trois places sont prises. (3) Tes favoris actuels ne se distinguent que par une étoile orange dans la liste. (4) Le pictogramme caméra est répété sur toutes les lignes, même sans caméra.
